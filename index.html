Key Features

Instant Listing Creation

Enter ISBN or scan barcode; the system auto‑populates title, edition, and cover image. Add condition, price, photos, and optional boost. Validation ensures required fields with a 30‑second max response time.

Smart Search & Filter

Full‑text search with filters for course code, ISBN, price range, condition, and proximity to campus. Results load within 200 ms for up to 10 k listings, with pagination and caching.

In‑App Messaging & Transaction Flow

Secure chat starts automatically when a buyer clicks “Contact Seller”. Integrated PCI‑DSS‑compliant Stripe payment with escrow; funds released after buyer confirms receipt. Includes timeout handling and automated dispute tickets.

Rating & Trust System

After each transaction, both parties rate each other 1‑5 stars with optional feedback. Seller rating influences search ranking. Listings dropping below 1‑star trigger admin review.

Admin Console & Moderation Tools

Role‑based UI for reviewing flagged listings, managing bans, viewing audit logs (90‑day retention), and generating weekly compliance reports. Bulk actions and AI‑assisted fraud detection flags.
